# HoraTrack

Application Android de suivi du temps de travail, historique, pauses, rapports, widgets et sauvegarde cloud.

Branche de reconstruction active : `rebuild/diamond-celestial-v2`.

## Ordre de stabilisation

1. Sécurité et conformité cloud : règles Firestore, confidentialité, versions APK.
2. Intégrité des pointages : GPS, pauses automatiques, sources de session.
3. Fiabilité des calculs temps/salaire.
4. Tests automatiques et installation instrumentée.
5. Migration progressive du stockage vers une architecture plus robuste.
6. Nettoyage du code mort et des anciens moteurs expérimentaux.
7. CI de publication complète.
